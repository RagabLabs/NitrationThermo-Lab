# Changelog

## 2.0.0 — 2026-10-17

- Redesigned the existing interface as Thermal Energy Observatory.
- Added the original reactor SVG, educational energy explorer and indexed catalogue.
- Added IBM Plex Sans Arabic, larger type, equation reflow and symbol definitions.
- Redesigned the analysis workspace, result panels, charts and navigation.
- Preserved the scientific engine, all twenty calculators and export/deployment behavior.
- Added golden-result, file-preservation, equation and accessibility/reflow tests.
- See UI-REDESIGN-CHANGELOG.md and docs/VALIDATION.md for details.

## 1.0.0 — 2026-10-16

- Added 20 TypeScript thermodynamic calculators in four scientific groups.
- Added Arabic RTL and English LTR, light/dark themes, local Inter and Cairo.
- Added KaTeX equations, computed Recharts plots, data tables and worked steps.
- Added physical input-unit conversion and selectable result display units.
- Added sourced standard liquid formation data and NIST water Shomate Cp.
- Added explicit endpoint/table dilution enthalpy input; no invented acid data.
- Added validity checks, limiting-reactant rejection and measured heat residuals.
- Corrected the reversed Btu/lb ↔ cal/g direction in the source lecture.
- Added JSON/CSV/text export, clipboard copy and browser print/PDF.
- Added numerical tests, Playwright browser tests and a GitHub Pages workflow.
